# Research Agent GUI

Streamlit UI for `starter_v0/chat.py`.

Run from `starter_v0/`:

```powershell
.\.venv\Scripts\Activate.ps1
python -m streamlit run GUI\app.py
```

Default OpenRouter model:

```text
openrouter/free
```

The UI writes transcript JSON files to:

```text
starter_v0/transcripts/
```

Do not paste API keys or private data into chat prompts.
